# От пылинки до чёрной дыры

Idle-рогалик для телефона (горизонтальный режим) на Godot 4.3, GDScript.
Ты пылинка в диске молодой звезды: собираешь пыль, растёшь, копишь валюту
и прокачиваешь древо навыков. Финальная цель — стать чёрной дырой.

## Как запустить
1. Открой Godot 4.3 (или новее 4.x), «Импорт» → выбери `project.godot`.
2. F5. На ПК мышь работает как палец: зажми в левой половине экрана — появится стик.
   Также работают WASD/стрелки, Tab открывает древо, Esc/Tab закрывает.

## Что есть в каркасе
- Плавающий стик слева, кнопка «Древо» справа; древо ставит игру на паузу,
  двигается пальцем, масштабируется щипком (колесом мыши на ПК).
- Пыль трёх уровней размера (1 = +1 валюты, 2 = +2, 3 = +5). Пыль выше открытого
  уровня видна с цветной обводкой и отталкивается.
- Четыре материала по зонам диска: металл и силикаты у звезды, лёд и углерод
  за снеговой линией (пунктирные кольца вокруг звезды).
- Состав тела: полоса долей материалов с отметками 40% и 50%, тип тела и его бонусы
  (специализация или смесь «Хондрит»).
- Скопления пыли (уровень 2 реже уровня 1), всплывающие «+N» цветом материала.
- Стрелка у края экрана указывает на звезду. Автосохранение каждые 10 секунд.

## Где что настраивать
- `data/skills.json` — узлы древа: стоимость, рост цены, макс. уровень, позиция
  на сетке, требования (`requires`, `requires_all`) и эффекты.
- `scripts/data/game_data.gd` — уровни пыли, материалы, зоны, типы тела, стадии.
- `scripts/world/player.gd` — скорость, радиус и сила притяжения.
- `scripts/world/dust_field.gd` — плотность пыли, сгустки и нити, скопления, орбитальный дрейф.
- `tools/gen_dust_atlas.py` — рисует текстуры пылинок в `assets/dust/dust_atlas.png`
  (строки: силикаты, металл, углерод, лёд; по 4 формы). Запуск: `python3 tools/gen_dust_atlas.py`.

## Звезда
- `shaders/young_star.gdshader` — то, что в игре: поверхность берётся из запечённой
  карты `assets/star/star_surface.png`, а вращение, кипение, пульсация вспышек, лучи
  и протуберанцы анимируются на лету.
- `shaders/young_star_procedural.gdshader` — исходник поверхности (тяжёлый). Если
  поменяешь в нём вид поверхности, перенеси изменения в `shaders/bake/star_surface_bake.gdshader`
  и перезапеки: открой `tools/bake_star.tscn` и нажми F6.
- `shaders/young_star_relief.gdshader` — запасной рельефный вариант.

## Структура
```
scenes/main.tscn          корневая сцена
scripts/main.gd           сборка мира, камера, интерфейс
scripts/autoload/         GameState (сохранение, валюта, масса), Skills (древо)
scripts/world/            игрок, пыль, звезда, звёздный фон
scripts/ui/               HUD, стик, экран древа
data/skills.json          данные древа
```

## Сборка на Android
Editor → Manage Export Templates (скачать шаблоны), указать Android SDK в
Editor Settings → Export → Android, затем Project → Export → Add → Android.
