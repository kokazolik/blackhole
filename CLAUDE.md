# ПАМЯТКА-НАДЗОР для Claude (читать перед каждым шагом)

Игра «От пылинки до чёрной дыры», Godot 4.3, Android. Автор пишет по-русски,
отвечать по-русски. Этот файл контролирует работу: перед каждой правкой,
перед сборкой и перед ответом автору пройти по нему сверху вниз.

## 1. Главное правило игры (выше всех остальных)

**У каждого состава тела своя игра, или хотя бы чуть-чуть своя, смотря какой
состав и какой тип тела.**

Каждая новая механика, событие, эффект или этап проверяется вопросом:
«чем это отличается для льда, камня, металла, углерода, хондрита, титана,
венеры, переходного тела?» Если ответ «ничем», механика не готова.

Типы тела (`GameData.body_type`): unformed, специализации (>50% одного
материала), хондрит (все ≤40%), дуо titan (лёд+углерод) и venus
(силикат+углерод), переходное (neutral, ведёт лидер). Флейворы гиганта:
giant_cold, giant_ice, giant_dark, giant_dense, giant_hot.

## 2. Рамки текущей большой работы

- Звук НЕ трогаем. Всё остальное можно и нужно.
- «Серьёзные исправления, большая работа»: не косметика, а заметные для
  игрока изменения.
- Визуал: реализм, без мультяшности. Сравнивать с лучшим, что уже есть в игре
  (шейдеры планеты, диск), а не с собой вчерашним.
- Не ломать сохранения: новые поля читать через `get(key, default)`.

## 3. Обязательная проверка каждой правки

1. Прочитал файл целиком перед правкой, а не по памяти.
2. Правка различается по составу/флейвору (правило 1).
3. `godot --headless --import` без ошибок и предупреждений по скриптам.
4. Бот-прогон на затронутом этапе (по одному боту за раз, не параллельно):
   - `_bot/bot.gd`: comp=rock|mid|ice|metal|stone|carbon|mix|titan|venus|trans,
     stage, km (пыль 0.0000004, галька 0.00002, валун 0.0005,
     планетезималь 8), route=planet|giant|none, shots, tag.
   - `_bot/giant_bot.gd`: r, flavor, skills, idle, moons, e, shots, tag.
   - Минимум два разных состава/флейвора на каждую механику.
5. Скриншоты ОТКРЫТЬ и посмотреть глазами, а не только проверить, что файл есть.
   Видно ли новое? Читается ли текст на телефоне? Нет ли наложений?
6. Если что-то не проверено, честно написать автору, что не проверено.

## 4. Сборка (каждый раз одинаково)

1. `export_presets.cfg`: поднять `version/code` и `version/name`.
2. `package/signed=false`, `mv _bot /tmp/_bot_keep`.
3. `HOME=/root timeout 300 godot --headless --import`.
4. `godot --headless --export-release Android build/u.apk`.
5. `python3 /tmp/sdk/sign_v2.py build/u.apk build/dust-to-blackhole-$V.apk /tmp/sdk/k.p12 dust2blackhole`.
6. `/tmp/venv/bin/apksigtool verify` — должно пройти.
7. Вернуть `signed=true` и `_bot` на место.
8. Коммит `scripts shaders data scenes export_presets.cfg CLAUDE.md`, пуш в
   `claude/project-thread-vu3f7u`.
9. Ветка `apk` (/tmp/apkbr): старый apk `git rm`, новый + копия
   `dust-to-blackhole.apk`, версия в README, скриншоты в `shots/`, пуш.
10. Копия apk в `/mnt/project-files/dust-to-blackhole/`.

Ссылка на скачивание: https://github.com/kokazolik/blackhole/raw/apk/dust-to-blackhole.apk

## 7. Уроки (ошибки, которые уже случались)

- Правка через python `str.replace` молча ничего не делает, если отступ не
  совпал. Всегда `assert old in s` перед заменой и проверять grep после.
- Скриншот без видимой новой фичи — значит фича не работает, а не «не видно».
